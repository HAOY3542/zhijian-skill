# 视觉与表达适配

这是样本观察，不是强制母版。用户模板、品牌规范和修改边界优先。

## 稳定特征与可变外观

管理汇报经常将主题放在上方，接一段判断或工作摘要，下方用数据表、对比图、流程、地图或实际截图展开。橙色负责章节与分组，红色强调关键差异、问题或动作。证据密度较高，文字与图表直接对应。

培训和早期项目方案另有蓝紫、玫红、棕色等体系，常见提问式大标题、概念拆解、案例截图与分步动作。字体也随时期和模板变化。不能把一个集团模板、固定字体或某一套配色当成周智健的唯一风格。

没有指定模板时，可用干净的浅底、清楚的主题标题、少量强调色，优先保证信息关系。不要求每页都有橙条、底部口号或集团标识，不复制无授权素材。

## 按任务选页面

| 页型 | 适合承载的内容 | 保留的信息关系 |
|---|---|---|
| 结果比较 | 目标与实际、项目 / 通路对比 | 同口径表格或图表，附近给判断与差异解释 |
| 断点诊断 | 获客到转化的环节问题 | 各环节结果、卡点、动作对应，避免只画漏斗不写数据 |
| 通路总图 | 多类获客与资源配置 | 每条通路对应对象、策略、承接与投入重点 |
| 机制流程 | 平台与项目分工、线索转化、服务流程 | 责任人 / 角色随环节标注，配实际输出与异常处理 |
| 节点排期 | 首开、活动、冲刺计划 | 时间横轴、通路或动作纵轴，明确目标与节点 |
| 案例实证 | 传播内容、带看服务、经服执行 | 一段背景与结果，关键过程截图，指出可复制条件 |
| 盈利测算 | 模式与成本比较 | 输入、假设、公式、情景、盈亏条件清楚可查 |

## 密度控制

样本中细表很多，但小字号和满屏内容不是需要复制的目标。先按阅读场景突出主信息，再安放明细。用户允许重组时可拆页或附录；固定页数、固定内容时保留信息，优化对齐、间距、局部放大和层级，必要时说明可读性限制。

表格用颜色编码有业务含义的差异；截图保留所需上下文并标注观察点，避免靠大段标题替截图解释。饼图仅用于少量互斥组成；跨期、跨通路对比可按实际需要选更易比较的图形，不强行模仿历史图表。

用原生文字、表格、图表及可编辑流程表达业务。不要将信息页面重画为一排无含义卡片，也不要将整页压成图片。

## 两项限制

提取出的字体、字号、色值只表示文件中的局部设置，不一定包含母版继承或组合对象变换。PDF转换也可能发生替字和换行变化，最终排版以实际交付环境为准。

本次视觉结论来自全量文件的代表页抽样，不能宣称已逐页审核原始522页的排版。
