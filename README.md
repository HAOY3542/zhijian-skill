# ZHIJIAN SKILL

**先算账，再说话。**

很多营销汇报，讲的都是"做了什么"：办了几场活动，拓了多少资源，发了多少条视频。领导真正想听的是另一件事：

> 花了多少，换来多少，还要不要继续投？

ZHIJIAN SKILL 整理自地产营销平台负责人周智健的二十多份汇报。他做过渠道经理、营销经理，现在一个人统管平台的品牌、费控、策划和渠道。他的汇报，几乎每一页都在回答上面那个问题。

装好这个技能以后，AI 会照他的路子帮你写汇报、搭方案、立规则，也能在你上会前先替领导挑一遍刺。

## 一句话的差别

同一件事，常见的写法是：

> 本季度大力拓展合作资源，新增注册 300 人，渠道建设成效显著。

照他的路子会这样写（数据为虚构）：

> **■ 合作资源：新增 300 人，但真正带来客户的只有 12 人，比上季度还少 5 人。**
> 现状不足：拉新有考核，维护没考核，人进来了就没人管。
> 改进措施：① 按活跃程度把资源分成三层，每层定好维护频次和负责人，月底前完成；② 下季度只考核带来客户的人数，不再考核注册数。

第一种写法讲的是忙了多少，第二种写法讲的是哪里没做好、打算怎么补。

## 他的六个习惯

**开口先算账。** 投入了什么，换来了什么，和什么比。只有过程、没有结果的，直接标"效果待核"。

**有问题先说自己的。** 复盘从自己的差距说起，而且说得很具体：一个没人看的群，一份没更新的台账，一条没人跟的线索。

**看板后面必须跟措施。** 指标列完，紧接着写"现状不足"和"改进措施"。只有数字的看板，在他那里不算写完。

**找到卡住的那一环。** 从起点到结果拆成几步，找出卡在哪一步，在那一步配人、配动作。不写"加强执行"。

**规则要写到能照着做。** 怎么判定、例外怎么办、谁说了算，三样缺一样都不算规则。

**要拍板就直说。** 需要领导决定的事单独放一页，写成"可否……，妥否？"，方案、代价、影响一起附上。

页面怎么排、话怎么说、各类汇报的骨架，以及一份预审清单，都写在 [SKILL.md](SKILL.md) 里。

## 能写什么

例会复盘、年度复盘和计划、体系规划、考核和激励方案、业务专题、新模式方案、首开或清盘这类节点作战方案、培训分享。也可以改稿，或者只调排版。

它不挑公司，也不挑数据：手上有几期数据就比几期，没有历史数据就和目标比，什么都没有也会把需要补的数据列出来给你。模板一律用你自己的。

## 装好它

以 Claude 为例：

1. 到 [Releases](https://github.com/HAOY3542/zhijian-skill/releases) 下载最新的 `zhijian-skill-v1.3.zip`。
2. 在 Claude 里打开 **Customize > Skills**，点 **+** → **Create skill** → **Upload a skill**，把 ZIP 传上去。传不上去的话，先到 Settings > Capabilities 里打开代码执行。
3. 在对话里说一句"用 ZHIJIAN SKILL 写这份复盘"，再把材料发给它。

## 你可以这样说

- 这是这个月的渠道数据，帮我写一页复盘，数据不够的地方标出来，别编。
- 我们想把老带新的奖励改一改，帮我写一版规则，例外情况也写清楚。
- 下个月要首开，帮我搭一份渠道作战方案的框架，告诉我还缺哪些数据。
- 明年费用要砍两成，帮我写一页调整方案，说清楚砍哪里、缺口谁来补。
- 这份方案下周上会，你先当领导过一遍，看看会在哪几页被问住。
- 只调这三页的排版，文字和数字一个都别动。

## 和 XUEYANG SKILL 一起用

[XUEYANG SKILL](https://github.com/HAOY3542/xueyang-skill) 管的是一份汇报怎么讲清楚：一页一个结论，数字经得起追问。ZHIJIAN SKILL 管的是这件事值不值得做、规则怎么立、执行怎么盯。两个可以一起装，各管各的。

## 说明

- 仓库里只有方法，没有任何原稿、项目数据、客户信息或公司模板。示例里的数据都是虚构的。
- 样本里渠道和费控最多，品牌和策划少一些，这两块会根据大家的反馈慢慢补。
- 这套方法整理自原稿里看得见的做法，不代表周智健本人或任何公司。

用得顺手，或者哪里不顺手，欢迎提 Issue，最好附上你的岗位、汇报类型和改前改后的写法。历次改动见 [CHANGELOG.md](CHANGELOG.md)。
