# ZHIJIAN SKILL

**周智健平台营销统筹与汇报方法 · v1.1**

连接地产平台的品牌、费控、策划和渠道工作，将经营问题落实为费用口径、执行体系、制度条款和决策诉求。

## v1.1 融合版

本版整合两份方法提炼稿，并吸收 v1.0 的任务适配和数据纪律，进一步具体化十二条方法、页面组织、措辞、八类汇报骨架、经营公式和制度模板。本次原样发布融合版，后续调整另行形成 v1.2。

完整版本变化见 [更新日志](CHANGELOG.md)。

## 下载与使用

下载 [v1.1 技能包](https://github.com/HAOY3542/zhijian-skill/releases/tag/v1.1)，解压后得到 `zhijian-skill/SKILL.md`。将技能目录放入所用工具的技能目录，或直接向助手提供这份文件。

本版为单文件技能，页面方法和示例均已写入 `SKILL.md`。历史 [v1.0](https://github.com/HAOY3542/zhijian-skill/releases/tag/v1.0) 保留下载。

支持起草汇报、机制与制度设计、经营测算、改稿、仅优化排版、预审和培训分享。用户自己的母版、页数及修改边界优先。

调用示例：

> 请用 ZHIJIAN SKILL，根据我的数据做3页平台获客复盘，写清通路卡点、平台支持和下阶段动作，缺失数据不编。

> 只优化这一页排版，文字、数字、日期和页序不变，口径疑点另列。

> 从平台费控视角审阅这份方案，区分预算、发生、支付与实际结果。

## 来源与适用边界

基础样本共22份精选工作材料、522页，包含个人署名培训、项目与城市汇报及集团制度资料。v1.0 完成可提取文字与结构梳理、66页视觉抽样及六个模拟场景试用；v1.1 完成文本对照、相关源页核查、公式反例复算及三种情境的指令走查。上述检查不等于真实业务效果或PPT成品验收。

渠道经营、费用效率、平台机制与获客策划证据较充分；品牌主要支持内容、服务、口碑与信任协同，独立品牌战略及舆情专题仍需更多样本。

本次保留 v1.1 原文。规则适用范围、盈亏公式条件、无样本评分处理与内部材料脱敏边界的审阅建议，留待 v1.2 校准；不将这些建议标记为已修复。

历史佣金、政策、考核权重和平台规则不作为当前通用标准。示例数据为虚构。原始PPT、截图、客户明细及内部经营数据不在本仓库中。

本项目不代表本人或任何企业的官方发布与背书。
