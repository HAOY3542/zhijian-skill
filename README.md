# ZHIJIAN SKILL

**周智健平台营销统筹与汇报方法 · v1.0**

把业务拆成可经营的通路，把通路拆成可执行的环节，再让费用、人员、制度与结果相互对应。

这套技能连接地产平台的品牌、费控、策划和渠道工作，适用于平台统筹、项目获客、渠道复盘、费用效率分析、机制建设及实操培训。

## 核心方法

- 从经营问题出发，分清通路与资源优先级。
- 内容与流量接到线索分配、邀约、到访和反馈，先保证承接能力。
- 按活跃度、需求与能力经营伙伴资源，以真实服务和履约体验建立信任。
- 将人员、激励、客户保护、费用与流程放在同一方案中考虑。
- 先做项目试点，形成流程与工具，再验证跨项目复制条件。
- 同时看业务规模、全成本与通路依赖，用复盘调整投入结构。

## 使用方式

下载 [v1.0 技能包](https://github.com/HAOY3542/zhijian-skill/releases/tag/v1.0)，解压后将 `zhijian-skill` 文件夹放入所用工具的技能目录，或直接向助手提供 `SKILL.md` 及其引用文件。

支持四种任务模式：起草、改稿、仅优化排版、预审。也可用于培训与方法沉淀。

调用示例：

> 请用 ZHIJIAN SKILL，根据我的数据做3页平台获客复盘，写清通路卡点、平台支持和下阶段动作，缺失数据不编。

> 只优化这一页排版，文字、数字、日期和页序不变，口径疑点另列。

> 从平台费控视角审阅这份方案，区分预算、发生、支付与实际结果。

## 来源与适用边界

v1.0 从22份精选工作材料提炼，共522页可提取文字与结构，实际查看66页代表页面，并完成六个模拟场景试用。材料包含个人署名培训、项目与城市汇报、集团制度资料；不主张所有文件均为个人独立原创，也不代表本人或任何企业的官方发布与背书。

样本最充分的部分是渠道经营、费用效率、平台机制和获客策划。品牌目前主要覆盖产品内容、服务、口碑和合作信任；独立品牌战略、舆情等专题仍需更多材料支持。

历史佣金、政策、考核权重和平台规则不作为当前通用标准。全部示例数据为虚构。源PPT、截图、客户明细与内部经营数据不在本仓库中。

结构检查与模拟试用不等于真实业务效果或PPT成品验收。
